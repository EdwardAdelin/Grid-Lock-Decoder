# Grid-Lock-Decoder
Using the famous "NYC Taxi Trip Data" (which has billions of rows detailing pickup/drop-off times and locations), I wrote a Hadoop job to find the absolute worst hours of the day to travel between specific city zones, based on average trip duration.

# Download the Database from Kaggle
link: 
https://www.kaggle.com/datasets/elemento/nyc-yellow-taxi-trip-data?resource=download&select=yellow_tripdata_2016-01.csv

Use the "yellow_tripdata_2016-01.csv(1.71 Gb)". It is the smallest in size.
